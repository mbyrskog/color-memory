# Color Memory

A simple memory card game built with React, TypeScript and Vite.
The objective is to find all matching color pairs while minimizing mistakes.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- Functional components + hooks

## 🎮 Features

- Shuffle logic
- Score system (+1 match / -1 mismatch)
- Locking during pair resolution
- Reset functionality

## 🛠 Run locally

- npm install
- npm run start
